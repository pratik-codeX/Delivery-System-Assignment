# Delivery System Assignment

This is a simple Python assignment for a delivery system.

The program reads delivery data from a JSON file, assigns packages to the nearest delivery agent, calculates total delivery distance, and creates `report.json`.

## Files

- `delivery_system.py` - main Python program
- `report.json` - output report generated by the program
- `test_delivery_system.py` - test file used to check the solution

## How To Run

Run this command:

```bash
python3 delivery_system.py
```

It will read:

```text
Python Assignment -2026/base_case.json
```

And it will create:

```text
report.json
```

## Run With Another Test Case

Example:

```bash
python3 delivery_system.py "Python Assignment -2026/Python Assignment(Delivery System Test Cases)/test_case_1.json"
```

## How To Test

Run:

```bash
python3 -m unittest -v
```

All provided test cases are checked by the test file.

## Logic Used

1. Read warehouses, agents, and packages from JSON.
2. For every package, find the nearest agent from the package warehouse.
3. Calculate distance using Euclidean distance formula.
4. Add pickup distance and delivery distance.
5. Count delivered packages for each agent.
6. Calculate efficiency as total distance divided by delivered packages.
7. Select the best agent with the lowest efficiency value.

## Assumptions

- Every package belongs to one warehouse.
- If an agent delivers a package, the agent current location becomes that package destination.
- If two agents have the same distance, agent id is used to keep the result fixed.
- If input data is wrong, the program shows a simple error message.
